# KËR · Enfin au courant

KËR suit un compteur prépayé Woyofal (Senelec) : crédit restant, tranches, autonomie et vrai coût de chaque recharge.

- Web app installable (PWA), fonctionne sans connexion.
- Aucune donnée ne quitte le téléphone : pas de compte, pas de serveur. Export, import et envoi volontaire seulement.
- Barème CRSE 2026 (Décision n°2025-140) : 82 F/kWh jusqu'à 150 kWh, 136,49 F/kWh au delà, taxe communale 2,5 %, TVA 18 % au delà de 250 kWh.
- La retenue d'environ 430 F sur la première recharge du mois est une hypothèse tirée de reçus réels, pas une règle confirmée.

Version de test. Retours bienvenus.
